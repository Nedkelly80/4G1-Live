4G1 LIVE — BEFORE YOUR FIRST CONNECTION

1. Install the 32-bit J2534 driver supplied by your adapter manufacturer.
2. Connect the adapter to the PC and vehicle with the ignition in RUN.
3. Open 4G1 Live, select the correct vehicle profile, then choose Connect.
4. Use Explore Demo at any time to learn the dashboard without a vehicle.

4G1 Live is a diagnostic aid. Do not operate the software while driving.
Use a second person for road testing and confirm all repairs against the
applicable Mitsubishi factory service information.

Application settings and logs are stored in:
%LOCALAPPDATA%\4G1 Live
